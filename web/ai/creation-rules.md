# FarkPG – Creation rules

How character building works mechanically: point buy, pools, and limits. These rules are informed by the **theme** (system data). How a particular tool (e.g. the static site builder, a spreadsheet, or an app) presents or runs creation is up to that tool.

## Point buy

- Character building is **point buy**: players spend points from defined pools to set attribute values, skill values, and abilities. Pools and limits are set by the theme (see [System data](system-data.md)).

## Point pools

- **Attribute points**: A single pool for raising attributes. Each theme defines the total and per-attribute min/max/default.
- **Skill points**: Usually **per category** (e.g. Combat, Social, Knowledge). Each category has its own pool and optional per-skill max.
- **Ability points**: A pool spent to buy abilities. Levelable abilities cost per level; others cost a flat amount.

## Custom options (data)

- Themes may allow **custom skills** per category (user-defined label, optional attribute link, value) and **custom abilities** (label, description, cost, levelable or not). Custom data is part of the character and persists in export/import (see [Character schema](character-schema.md)).

## Editable totals

- Max points per pool may be editable (e.g. for GMs or house rules). How that is exposed is tool-specific; theme defaults define the standard pools.
