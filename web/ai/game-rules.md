# FarkPG – Game rules

General rules for how the game works. (Expand with full text as the system is finalized.)

## Core resolution: Farkle

- **Farkle** is the core resolution mechanic. Actions are resolved by rolling dice using standard Farkle rules.
- The number of dice rolled for an action is determined by **attributes + skills** (as defined in system data and the character).
- **Max dice rolled is always 6.** Any value over 6 (from attributes + skills) gives **1 free re-roll** during that Farkle roll. Free re-rolls are used before or between rolls as defined (e.g. in combat they last the whole turn; see Combat).

## Resource currency

- Systems should define a **resource currency** that lets players attempt Farkle without losing progress when they fail a roll.
- A player may spend **1 currency per roll** during Farkle play to **retain rolled values** (i.e. not lose them on a failed roll). This must be **declared at the start of that Farkle roll**. Each roll that uses this protection consumes 1 resource.

## Combat

- **Initiative**: Combat uses a simple initiative system (e.g. roll or stat-based order).
- **Actions**: Each player has **2 actions** per turn. Actions are flexible and can be repeated.
- **Free re-rolls**: Free re-rolls from attributes + skills (values over 6) last through the **whole turn**, not per action.

## Attributes and skills

- **Attributes** are core stats (e.g. Strength, Agility, Endurance, Intelligence, Willpower, Charisma). They have numeric values and often bounds (min/max/default).
- **Skills** are grouped by category (e.g. Combat, Social, Knowledge). Each skill may be tied to an attribute and has a numeric value. Attribute + relevant skill (or similar) feeds into how many dice are rolled.

## Abilities

- **Abilities** are special traits a character can have. They may be one-off (bought once) or levelable (multiple ranks). Each has a cost in character-building points.

## Experience (XP)

- Characters have an **XP** (experience) value. Use it for advancement, unlocks, or system-specific rewards as defined by the theme or campaign.

## Character building

- Character building is a **point buy system**: players spend points from defined pools (attributes, skills per category, abilities) to set values and buy abilities. See [Creation rules](creation-rules.md) and [System data](system-data.md) for pools and limits.

## Design goals

- **Rules lite**: Keep the system simple and quick to run.
- **Flexible**: Support different settings and builder variants via themes/config.
